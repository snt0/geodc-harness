# geoDC pull request template

Fill a geoDC pull request body in this shape. Swap "Part of" for the closing keyword only when every criterion is
met, dropped or moved ([github-practices.md](github-practices.md)).

```markdown
Part of #N

## What changes


## Testing

### Done

<!-- What ran and where: Linux test projects, compile-only, Windows run, UI driver. -->

### Still to verify

<!-- Steps someone else must take, e.g. a Windows run of geoDC.App.Tests or a live UI check. "None" if nothing. -->
```
